# Dober コンテンツフォーマット定義（共有）

`dober-content-strategy`（投稿生成）と `dober-strategy-review`（実例の分類・更新提案）が共通で参照するA〜Gフォーマットの定義。投稿の分類・生成はすべてこの7区分に基づく。

2026-07-11時点では、過去CSVの **5000インプレッション以上の投稿** を優先データとして扱う。直近分析や旧スコアリングより、実際にリーチした投稿の構造を優先する。

## 現行の優先フォーマット

| 区分 | フォーマット | 概要 |
|------|------------|------|
| A | 危機・負債型 | 「人生が詰む」「人生を台無しにする」「ハードモードになる」など、放置すると損失が返ってくる構造。20代/30代、習慣、身体、金、失敗回避と相性がよい |
| B | 基本基準・できないこと型 | 「ほとんどの男性ができないこと」「男の基本」など、読者の現在地を測るチェックリスト。身体能力、生活管理、金銭管理、感情制御を並べる |
| C | 社会が思う/本当の価値 対比型 | 「社会が思う成功 / 本当の成功」「世間がかっこいいと思っているもの / 本当にかっこいいもの」など、見せる価値と実際の自由を対比する |
| D | 人工刺激・やめる/やる型 | AV、酒、スクロール、ジャンクフード、通知、見栄消費など、活力を奪うものを列挙し、代替行動を示す |
| E | 退屈な規律型 | 「退屈な男」「つまらない人になろう」など、早寝・筋トレ・自炊・読書・散歩・静かな蓄財を新しいかっこよさとして提示する |
| F | 階層・ステージ分類型 | 「現代男性のステータス階層」「上位1%への道」「IQ/EQ分類」など、平均/平均以上/最上位やステージで読者を位置付ける |
| G | 恋愛・女性視点の選別型 | 「女性が男を見る基準」「結婚前に見るべきこと」「モテないのではなく見抜かれている」など、恋愛を生活管理・余裕・選ぶ力に接続する |

## 生成配分

- 週21本なら、A〜Eを各3〜4本、F/Gを各2〜3本程度にする。
- C（社会が思う/本当の価値）は、直近で突出実績があるため毎週2本以上入れる。
- 単なる「お金の使い方」訓話は弱い。お金テーマはC/F型の「自由・仕組み・金で買える/買えない」の構造に寄せる。

## 優先しないフォーマット

- アルファ/シグマ フレームワーク型は、5000imp超データ内の出現が少なく直近でも伸びが弱いため、通常ローテーションから外す。
- 有名人逸話型は単体では優先度を下げる。使う場合は「ザ・ロックの朝」「規律の反復」などE/F型に接続する。
- 抽象的な短文断定型は、単独で量産しない。C/D/Eの構造内で締めとして使う。
